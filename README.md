### Финална стъпка за активиране на имейл известията (отнема 1 минута):

1. Влез в профила си в Google -> [Security -> App Passwords](https://myaccount.google.com/apppasswords) и създай нова парола за приложение с име `PriceBot` (16-символен код).
2. Отвори настройките на хранилището си в GitHub:
   👉 **[`https://github.com/Martincho2003/apartament-price-bot/settings/secrets/actions`](https://github.com/Martincho2003/apartament-price-bot/settings/secrets/actions)**
3. Натисни **New repository secret** и добави следните 3 секрета:
   - `SMTP_USER` — твоят Gmail адрес
   - `SMTP_PASS` — 16-символната парола за приложение от Стъпка 1
   - `NOTIFY_EMAIL` — имейлът, на който искаш да получаваш известията
